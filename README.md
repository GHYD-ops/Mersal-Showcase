# Mersal | مِرسال

**Making every occasion a little more memorable.**

Mersal is an independently developed digital brand focused on creating elegant, interactive, and personalized experiences for special occasions.

## About the Project

Mersal combines creativity, thoughtful design, and web development to offer modern digital greeting cards and personalized QR code experiences.

The project focuses on simplicity, accessibility, and creating meaningful digital experiences through carefully designed interfaces.

## Features

- Digital greeting cards for different occasions
- Personalized QR code experiences
- Elegant and modern UI/UX design
- Responsive layouts across devices
- Arabic and English language support
- Simple and accessible user experience
